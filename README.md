# know-naren

Personal portfolio for Narenkumar V R — Senior Software Engineer (AI/ML). A single-page, scroll-animated site covering experience, personal projects, skills, and education.

## Stack

- Vite + React + TypeScript
- Tailwind CSS
- Framer Motion (scroll-reveal animations)

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
